## Project Description
This project simulates an IoT temperature monitoring system using Python.

## Features
1. Generates 50 simulated temperature readings.
2. Saves readings in a CSV file.
3. Reads and analyzes temperature data.
4. Calculates minimum, maximum and average temperatures.
5. Displays a temperature graph.

## Requirements
- Python 3
- Matplotlib

## How to Run
Install Matplotlib using:
pip install matplotlib

Run the program:
python iot_temperature.py

Note: The temperature readings are simulated. No physical sensor is required.
